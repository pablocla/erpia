# Eslabón 1: Relevamiento

**Responsable:** Analista Comercial / Vendedor
**Objetivo:** Recopilar las necesidades del cliente y definir qué módulos y plan de Claver Cloud aplican.

## Checklist
- [ ] Entender rubro del cliente (Ej. Gastronomía, Retail).
- [ ] Listar módulos requeridos (Inventario, Facturación AFIP, Fiado).
- [ ] Definir el MRR estimado y si requiere hardware (IoT, KDS).
- [ ] Cargar los datos preliminares en el CRM/Pipeline.
